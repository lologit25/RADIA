# withhoney.com — brief de referencia

Fuente: https://www.withhoney.com/ (Framer). Inspeccionada a 1440×900 y 390×844.

## Paleta observada
| Uso | Valor | En el portafolio |
|---|---|---|
| Fondo | `#000000` | igual |
| Paneles | `#151515`, `#1f1f1f` | igual |
| Texto principal | `#f4f1ee`, `#ffffff` | igual |
| Grises | `#979797`, `#757575`, `#575757`, `#3d3d3d` | igual |
| Acento | `#f44849` / `#ff4c24` (coral) | **`#a9d8f5` celeste pastel** |

## Tipografía
- Titulares: Suisse Int'l 400, 120px / 110px, tracking −6px, degradado blanco → gris. → **Geist**.
- Etiquetas: GT Flexa Mono 10px / 12–15px, mayúsculas. → **Geist Mono**.
- (Suisse y GT Flexa no están en Google Fonts; Geist ya se usa en la propia web de Honey.)

## Secuencia → adaptación
| Honey | Portafolio |
|---|---|
| Nav mono + botón de acento | Nav mono + “Hablemos” celeste |
| Hero: objeto 3D que cae + titular gigante + logos | Escena 3D: miel negra que cae sobre una pluma fuente y sale por la punta como tinta + titular + logos reales en blanco |
| Panel “About” redondeado, texto que se ilumina al scrollear | “Sobre mí” |
| `[ 02 / 09 ]` Services: texto fijo + lista grande con foco | “Oficio” |
| Lista numerada de proceso | “Trabajos” (profesional) con vista previa que sigue al cursor; “Estudiante” aparte, en grilla chica |
| Bloque FAQ en color de acento | “Premios” en celeste |
| Franja “Where do I sign? / Here ↗↗↗” + wordmark gigante | “¿Hablamos? / Acá ↗↗↗” + “paolo” |

No se reutilizó texto, imágenes, video ni logos de Honey.
